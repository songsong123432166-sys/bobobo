# 程序运行逻辑说明

这份说明面向普通用户，用来解释健康提醒程序平时是怎样工作的。

## 程序启动后会做什么

程序启动后会待在 Windows 系统托盘里，不占用任务栏。

用户可以通过托盘右键菜单打开主界面、查看版本或退出程序。

主界面主要展示今天的健康状态，例如健康分、喝水次数、起身次数、电脑使用时长、当前是否正在使用电脑等。

## 程序怎样判断你正在使用电脑

程序会优先根据键盘和鼠标判断你是否正在电脑前。

如果你最近有移动鼠标或敲键盘，程序就认为你正在使用电脑。

这时：

- 久坐计时会继续计算。
- 状态灯显示绿色。
- 摄像头不会被频繁打开。

## 程序什么时候会打开摄像头

摄像头不会一直工作。

只有当键盘和鼠标超过一段时间没有操作后，程序才会短暂打开摄像头确认电脑前是否有人。

默认逻辑是：

- 键鼠超过约 20 秒没有操作，才考虑使用摄像头。
- 进入无人状态前，摄像头约 15 秒检测一次。
- 连续 3 次都没有检测到人，才进入无人状态。
- 进入无人状态后，摄像头约 1 分钟检测一次。
- 每次只短暂读取几帧画面。

程序不会保存摄像头画面，也不会上传画面。

## 摄像头怎样判断电脑前有没有人

程序会先用更灵敏的人脸模型尝试识别人脸。

如果人脸没有识别出来，还会继续尝试识别侧脸、上半身、全身和人体轮廓。

只要识别到人脸或人体，程序就认为电脑前有人。

如果连续几次都没有识别到人，程序才认为你离开了电脑前。

这样可以减少转头、遮挡、光线变化造成的误判。

## 状态灯是什么意思

主界面有三个状态灯：

- 绿色：电脑正在使用。
- 黄色：刚检测到你不在电脑前，还没有超过 20 分钟。
- 红色：你不在电脑前已经超过 20 分钟。

状态灯只是提示当前状态，不会打断你的操作。

## 久坐提醒怎样工作

程序会按设置的时间提醒你起身活动。

默认约 45 分钟提醒一次。

久坐提醒弹出后，不需要你点击“我起身了”。

程序会在提醒后的几分钟内观察你是否真的离开电脑前：

- 如果检测到你离开了电脑前，就自动记录一次起身。
- 如果一直检测到你还在电脑前，就不会记录起身。

这样可以减少手动点击，也能更接近真实行为。

## 喝水提醒怎样工作

程序会按设置的时间提醒你喝水。

默认约 60 分钟提醒一次。

喝水提醒会弹出确认窗口。

你可以填写或确认喝水量，程序会把它记录到今天的数据里。

如果暂时不想喝，可以选择稍后提醒。

## 久坐和喝水提醒会不会连续弹出

如果久坐提醒和喝水提醒时间很接近，程序会把它们合并成一个提醒。

这样可以避免短时间内连续弹出多个窗口。

默认合并范围约 5 分钟。

## 勿扰时间怎样工作

你可以设置一段勿扰时间，例如午休或会议时间。

在勿扰时间内，程序不会弹出普通健康提醒。

勿扰结束后，提醒会继续按新的时间计算。

## 离开电脑后会发生什么

当程序判断你已经离开电脑前时：

- 久坐计时会归零。
- 状态灯会变成黄色或红色。
- 程序会记住这次离席状态。

离开时不会立刻弹出中央窗口。

## 回到电脑前为什么会弹出中央窗口

中央离席原因窗口是在你“离开后回来”时弹出的。

它的作用是让你补充刚才离开的原因，例如：

- 上厕所
- 开会
- 抽根烟
- 外勤

选择后，程序会把这次离席记录到今天的数据里。

如果你不想记录，可以点“不记录”。

也可以直接按空格键或 Esc 关闭，程序会按“未记录”处理。

如果你在设置里关闭中央弹窗，那么回来后不会再弹这个窗口。

## 健康分是怎么来的

健康分会根据当天的行为综合计算。

主要参考：

- 喝水情况
- 起身活动情况
- 如厕频率
- 久坐连续时长
- 抽烟记录

分数不是医学诊断，只是帮助你了解今天的健康习惯是否更友好。

## 提示音怎样工作

提醒弹出时会播放提示音。

你可以在设置里调整提示音音量，范围是 0 到 100。

- 0 表示静音。
- 100 表示原始音量。

这个音量只影响程序自己的提示音，不会改变 Windows 系统音量。

## 开机自启怎样工作

如果开启开机自启，电脑启动后程序会自动运行，并常驻托盘。

如果关闭开机自启，程序只会在你手动打开时运行。

## 程序会保存哪些数据

程序会保存：

- 设置项
- 今日健康数据
- 历史健康数据
- 离席原因
- 运行日志

这些数据保存在本机，不需要联网。

## 程序退出时会做什么

点击托盘菜单里的退出后，程序会停止后台提醒、关闭托盘图标，并关闭所有窗口。

正常退出后不会继续弹提醒。

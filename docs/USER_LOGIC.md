# 健康提醒助手 — 运行逻辑说明

> 本文档面向普通用户，用通俗的语言解释程序在后台是怎么工作的。
> 你不需要懂编程也能看懂。

---

## 一、程序启动后在做什么？

程序启动后会最小化到 Windows 右下角的**系统托盘**（就是小箭头点开那一片区域），不占用任务栏位置。

它会在后台默默地做三件事：

1. **观察你是否在用电脑**（键盘鼠标 + 摄像头）
2. **定时提醒你喝水和起身**
3. **记录今天的健康数据并计算健康分**

---

## 二、程序怎么知道我在不在电脑前？

程序用**两层检测**来判断你是否在电脑前：

### 第一层：键盘和鼠标（优先）

程序通过 Windows 系统接口查询"你最后一次动鼠标或敲键盘是什么时候"。

- 如果你最近动过 → 程序认为**你在用电脑**
- 如果超过一段时间没动（默认 20 秒）→ 程序开始怀疑你离开了

### 第二层：摄像头确认（仅在需要时）

摄像头**不会一直开着**，只有在键盘鼠标长时间没操作时才会短暂打开来确认。

判断流程是这样的：

```
你停止操作鼠标键盘
      ↓
  等待约 20 秒
      ↓
  摄像头开始检测（每 15 秒一次）
      ↓
  检测到人脸/人 → 你还在电脑前
      ↓
  连续 3 次都没检测到人 → 确认你离开了
      ↓
  进入"离席状态"，摄像头改为约 1 分钟检测一次
```

### 摄像头怎么看有没有人？

摄像头拍到画面后，程序会用**三重检测**来找人：

1. **YuNet 深度学习人脸模型**（最准）— 专门识别人脸
2. **Haar 级联分类器** — 能识别正面脸、侧面脸、上半身、全身
3. **HOG 人体检测** — 识别人体轮廓

只要其中任意一种方法检测到人，就认为你在电脑前。连续多次都检测不到，才判定你离开。这样可以避免因为转头、遮挡、光线变化造成的误判。

**关于隐私**：
- 程序**不会保存任何摄像头画面**
- 程序**不会上传任何画面到网络**
- 你可以在设置里开启**隐私模式**，完全关闭摄像头，只用键盘鼠标来判断

### 状态灯的颜色含义

主界面有一个状态灯，颜色含义如下：

| 颜色 | 含义 |
|------|------|
| 🟢 绿色 | 你正在使用电脑 |
| 🟡 黄色 | 刚检测到你离开，还没超过 20 分钟 |
| 🔴 红色 | 你离开电脑已超过 20 分钟 |

## 三、久坐提醒是怎么工作的？

程序内部有一个**久坐计时器**，从你开始使用电脑时就开始计时。

### 提醒流程

```
你开始使用电脑
      ↓
  久坐计时器开始计时
      ↓
  达到设定时间（默认 45 分钟）
      ↓
  弹出提醒 + 播放提示音
      ↓
  程序自动观察你是否真的起身了
      ↓
  检测到你离开 → 记录一次"起身"，计时器归零
  没有离开 → 不记录，等下次提醒
```

**关键点**：你不需要手动点"我起身了"，程序会通过摄像头自动判断。提醒弹出后，你只需要真的站起来走动就行。

### 起身确认机制

弹出久坐提醒后，程序会在接下来约 3 分钟内持续用摄像头观察：

- 如果检测到你离开了座位 → **自动记录一次起身**，久坐计时归零
- 如果 3 分钟内你一直没离开 → **不记录**，等下一次提醒

---

## 四、喝水提醒是怎么工作的？

程序内部有一个**喝水计时器**，独立于久坐计时器。

### 提醒流程

```
上次喝水后开始计时
      ↓
  达到设定时间（默认 60 分钟）
      ↓
  右下角弹出提醒 + 提示音
      ↓
  弹窗持续 10 分钟，你可以：
    → 输入饮水量（如 200ml）并确认
    → 稍后再提醒（延迟 10 分钟）
    → 不操作（弹窗自动消失）
```

### 喝水与久坐提醒会合并

如果喝水提醒和久坐提醒的时间很接近（默认相差 5 分钟以内），程序会把它们**合并成一个提醒**弹出，避免短时间内连续弹两个窗口打扰你。

---

## 五、离席时发生了什么？

当程序确认你离开了电脑前：

1. **久坐计时器归零** — 因为你已经起身了
2. **状态灯变黄/变红** — 提示你不在电脑前
3. **记录离席时间**

当你回到电脑前，程序会弹出一个**离席原因窗口**，让你选择刚才去做什么了：

- 上厕所 → 会记录到健康数据
- 抽烟 → 会记录到健康数据
- 开会 / 外勤 / 其他 → 会记录离席次数
- 不记录 → 直接关闭

这些记录会影响健康分的计算。

## 六、健康分是怎么算出来的？

健康分满分 100 分，由**五个维度**加权计算：

| 维度 | 权重 | 说明 |
|------|------|------|
| 💧 喝水 | 25% | 今天的饮水量 |
| 🚶 起身 | 25% | 今天起身活动的次数 |
| 🚽 如厕 | 20% | 上厕所的频率和间隔 |
| 🪑 久坐 | 20% | 单次最长连续久坐时间 |
| 🚬 抽烟 | 10% | 今天抽烟的次数 |

### 每个维度怎么打分？

#### 💧 喝水（满分 25 分）

| 饮水量 | 得分比例 |
|--------|----------|
| 0 ml | 0% |
| 500 ml 以下 | 15% |
| 1000 ml | 30% |
| 1500 ml | 55% |
| 2000 ml | 80% |
| 2500 ml | 100%（满分） |
| 3000 ml | 90%（喝太多反而降） |
| 3000 ml 以上 | 75% |

> 适度饮水最佳，不是越多越好。

#### 🚶 起身（满分 25 分）

起身 8 次及以上得满分。公式：`得分比例 = 起身次数 / 8`，最高 100%。

#### 🚽 如厕（满分 20 分）

| 上厕所次数 | 基础得分比例 |
|------------|-------------|
| 0 次 | 25% |
| 1-3 次 | 30% |
| 4-5 次 | 60% |
| 6-8 次 | 100%（最佳） |
| 9-12 次 | 80% |
| 12 次以上 | 55% |

**额外扣分**：如果两次上厕所之间间隔超过 3 小时扣 20%，超过 4 小时扣 40%。这是因为长时间不上厕所对前列腺不好。

#### 🪑 久坐（满分 20 分）

| 单次最长连续久坐 | 得分比例 |
|------------------|----------|
| 30 分钟以内 | 100% |
| 45 分钟以内 | 90% |
| 60 分钟以内 | 75% |
| 90 分钟以内 | 50% |
| 120 分钟以内 | 25% |
| 超过 120 分钟 | 0% |

#### 🚬 抽烟（满分 10 分）

| 抽烟次数 | 得分比例 |
|----------|----------|
| 0 次 | 100% |
| 1-3 次 | 60% |
| 4-6 次 | 30% |
| 7-10 次 | 10% |
| 10 次以上 | 0% |

### 健康等级

| 分数 | 等级 | 含义 |
|------|------|------|
| 90+ | A | 前列腺友好日 |
| 75-89 | B | 不错，有改善空间 |
| 60-74 | C | 注意！有风险行为 |
| 40-59 | D | 今天伤害了不少，明天调整 |
| 0-39 | E | 高危日，建议复盘具体原因 |

程序还会自动分析你最薄弱的维度，给出针对性建议。

## 七、勿扰模式

你可以在设置里开启勿扰模式，设置一个时间段（比如午休 12:00-13:00）。在勿扰时间段内：

- 不会弹出任何提醒
- 但后台数据仍在记录（起身检测、久坐计时等正常运行）
- 勿扰结束后，提醒恢复正常

---

## 八、三种检测模式的区别

| 模式 | 摄像头 | 键盘鼠标 | 适用场景 |
|------|--------|----------|----------|
| 推荐模式 | ✅ 开启 | ✅ 开启 | 最准确，能自动确认起身 |
| 轻量模式 | ❌ 关闭 | ✅ 开启 | 不用摄像头，只靠键鼠判断 |
| 隐私模式 | ❌ 关闭 | ✅ 开启 | 同轻量模式，强调隐私保护 |

---

## 九、程序保存了哪些数据？

所有数据**只保存在你的电脑本地**，不会上传到任何服务器：

| 数据类型 | 保存位置 |
|----------|----------|
| 你的设置 | config.json |
| 今天/历史健康数据 | score.json |
| 离席原因记录 | away_log.json |
| 运行日志 | reminder.log |

## 十、常见问题

**Q：摄像头一直在开着吗？**
A：不会。摄像头只在键盘鼠标长时间没操作时才短暂打开，每次只拍几帧画面，拍完立刻关闭。

**Q：我不想用摄像头怎么办？**
A：在设置里开启"隐私模式"即可。程序会只根据键盘鼠标来判断你是否在电脑前。

**Q：健康分不准怎么办？**
A：健康分是一个参考指标，不是医学诊断。你可以通过手动记录喝水、上厕所、抽烟来让它更准确。

**Q：提醒太多能关掉吗？**
A：可以。你可以在托盘菜单里临时暂停提醒 30 分钟或 1 小时，也可以在设置里调整提醒间隔或开启勿扰模式。

**Q：程序会不会影响电脑性能？**
A：程序非常轻量，常驻内存占用很小。摄像头只在需要时短暂开启，不会持续占用资源。
